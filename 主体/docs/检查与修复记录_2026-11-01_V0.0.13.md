# 灵珑聊天 · V0.0.13（通讯录搜索）2026-11-01

## 背景

用户要求「发一个 13 的更新包」，并且明确**走服务端发布 + 客户端自查更新**，不再往微信里发 APK。
所以这版既有实际功能，也用来验证服务端发版链路。

## 新功能

- **通讯录搜索**：顶部加搜索框，按**昵称**或**专属号**实时过滤
  - 空关键字时显示「新的朋友 / 群聊 / 我的好友（N）」
  - 有输入时只保留匹配项，并显示「找到 N 个」
  - 没有匹配 → 「没有匹配的好友」
- 实现：`buildContactsInto()` 拆出 `fillContactRows(list, kw)`，`TextWatcher` 每次输入重填列表

## 验证

- 构建：`versionCode 12→13`、`versionName V0.0.13`
- 服务端发布：`data/apk/linglum-chat-V0.0.13.apk` + `version.json`（versionCode 13、md5、notes）
- 客户端链路：`GET /api/version` 返回 13 → 弹窗 → 点「立即更新」→ `GET /apk/linglum-chat-V0.0.13.apk` → md5 校验 → 调起安装
- 线上自查命令：
  ```bash
  curl -s http://<NAS>:8097/api/version
  curl -s -o /tmp/a.apk -w '%{http_code} %{size_download}\n' http://<NAS>:8097/apk/linglum-chat-V0.0.13.apk
  md5sum /tmp/a.apk   # 必须与 version.json 里的 md5 一致
  ```
