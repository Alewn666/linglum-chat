# 灵珑聊天 · 微信化改造路线图

> 目标：做成"能日常用"的微信式聊天 App。微信功能很多，分三期，每期都能独立发布使用。

## 第 1 期（V0.0.8，本轮）

- [x] **底部四页签**：微信 / 通讯录 / 发现 / 我（未选中灰、选中微信绿 #07C160）
- [x] **通讯录**：好友列表（头像 + 昵称）、群聊入口、新的朋友、点人 → 发消息 / 看资料（含安全码）
- [x] **我**：我的名片（头像 + 昵称 + 专属号）、换头像、改昵称、设置、帮朋友找回、同步日志、退出
- [x] **通讯录存服务端**（`friends` 表，双向）：换手机 / 找回账号后好友自动回来
- [x] **头像**：选图 → 裁方 → 压 256px → 上传；客户端按 `avatar_ver` 自动同步；没设头像用首字母色块
- [x] **新图标**：微信绿渐变 + 双气泡
- [x] 发现页先放占位（朋友圈 / 扫一扫 / 红包 标注"下一版"）

## 第 2 期（下一轮）

- [ ] **朋友圈**：发图文、点赞、评论、时间线（服务端 moments 表 + 图片）
- [ ] **好友请求**：加好友要先申请 → 对方同意（现在是一加即成双向）
- [ ] **消息操作**：长按菜单（复制 / 撤回 2 分钟 / 删除 / 转发）
- [ ] **表情面板**：常用 emoji + 收藏
- [ ] **聊天记录搜索**（本地）+ 联系人搜索
- [ ] **消息多选 / 批量删除**

## 第 3 期

- [ ] **语音消息**（录音 + 波形 + 时长）
- [ ] **群管理**：改群名、邀请/移出成员、群公告、@某人、免打扰
- [ ] **会话置顶 / 免打扰 / 删除会话**
- [ ] **备份与恢复**（导出加密聊天记录到文件）
- [ ] **深色模式跟随系统 / 字体大小**

## 明确不做（技术或成本不现实）

- 微信支付 / 红包：涉及钱和支付资质，不做
- 小程序 / 公众号：需要平台生态，不做
- 视频通话 / 语音通话：WebRTC + 穿透 + 带宽，NAS 上不现实
- 扫一扫：需要相机取景 + 识别库，收益低，暂不做
