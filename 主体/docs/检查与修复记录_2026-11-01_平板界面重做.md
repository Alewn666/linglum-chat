# 灵珑聊天 · 平板界面重做 + 扫一扫横竖屏（V0.0.17）

## 用户反馈

> 平板端丑到我了，而且平板端的扫一扫也有点问题。

截图里能看到的毛病：
1. 中间列表是**一块浮空的半透明圆角卡片**（`glass(20)` + rootCol 四周 24dp 边距），四周一圈空白，像浮在半空
2. 左栏色块从 y≈75 才开始、下面一直接到底，和卡片高度对不齐
3. 列表头「灵珑聊天」下面还挂着两个大胶囊（加好友/建群），占地方
4. 扫一扫在平板上被 `screenOrientation="portrait"` 锁成竖屏，横向平板打开变成竖条

## 改动

### 平板三栏（`showHomeTablet`）
- `rootCol.setPadding(0,0,0,0)` —— **铺满全屏**，不再四周留白
- 左栏：76dp，扁平色（暗 `#1B1B20` / 亮 `#F7F7F8`），顶部 28dp 起，条目上下 14dp
- 中栏：330dp，**纯色底**（暗 `#141418` / 亮白），不再用半透明玻璃，去掉大圆角
- 中栏与右栏之间加 **1px 分隔线**
- 右栏内边距 `16/8/12/8`，聊天区不再贴着边
- 会话列表头去掉「＋ 加好友 / ＋ 建群」两个胶囊（用右上角 ＋ 菜单就够），标题改「灵珑」

### 扫一扫（`QrScan`）
- Manifest 去掉 `screenOrientation="portrait"`，改为 `configChanges="orientation|screenSize|keyboardHidden"`
- 方向计算抽成 `applyOrientation()`，在 `openCamera` / `surfaceChanged` / `onConfigurationChanged` 三处重算
  → 手机竖屏 = 90°，平板横屏 = 0°，都能正立；旋转屏幕后立刻重算，不需要重开页面
