## 2. 路线图第 2 期：消息操作

| 功能 | 说明 |
|---|---|
| **长按菜单** | 复制 / 转发 / 撤回 / 删除（复制与转发只对文字消息出现） |
| **撤回** | 只有自己发的、且 **2 分钟内** 能撤；服务端 `POST /api/messages/<id>/recall` 校验发件人与时间；撤回后双方都显示「你/对方 撤回了一条消息」 |
| **删除** | 只删本机（`messages.jsonl` 整份重写），服务端密文不动 |
| **转发** | 弹会话列表（好友 + 群），选中即把文字再发一次 |
| **表情面板** | 输入栏左侧 😀，展开 40 个常用 emoji，点一下插入光标处 |

服务端：`messages.recalled` 列（迁移自动加）、`/api/messages` 下发 `recalled`。
