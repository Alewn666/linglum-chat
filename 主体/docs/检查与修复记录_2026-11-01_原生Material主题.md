# 灵珑聊天 · 改用安卓原生 Material 主题（V0.0.22）

## 用户诉求

> 能不能用安卓原生的 UI 呀？感觉还是太丑了，如果能用的话就用安卓的原生 UI 去做。

## 能做到什么 / 不能做到什么（先讲清楚）

**能（本轮做了）——平台自带 Material，零第三方库：**
- `@android:style/Theme.Material` 主题体系：`colorPrimary / colorAccent / windowBackground / statusBarColor`
- `android.widget.Toolbar`：系统 App Bar（自带高度、标题排版、高程阴影）
- `?android:attr/selectableItemBackground`：**系统水波纹**点击反馈
- 系统 `EditText`（Material 下划线输入框）、系统 `AlertDialog`、系统 `Switch`
- 深浅色各一套 `values/` + `values-night/`

**不能（工具链限制，需说明）：**
- AndroidX / Material Components 里的组件（`MaterialCardView`、`BottomNavigationView`、
  `RecyclerView`、`TextInputLayout`、`FloatingActionButton`）都打包在 **AAR** 里，
  需要 Gradle 那种"资源合并 + R 类生成"的流程；我们这套是裸 `aapt2 + javac + d8`，
  直接用 AAR 要自己造一遍资源合并，工作量大且容易翻车。
- 想要的话有两条路：① 我手写 AAR 资源合并（约一天，风险中）② 让项目切到 Gradle（NAS 上装 Gradle+依赖，体积和内存开销大）。

## 本轮改动

```
res/values/styles.xml      AppTheme（extends Theme.Material.Light.NoActionBar）
res/values/colors.xml      brand #10A37F / bg #F7F8FA / fg / muted
res/values-night/*.xml     深色主题（Theme.Material.NoActionBar + 深底色）
AndroidManifest            android:theme="@style/AppTheme"
```

代码侧：
- `topBar()` 改成 `android.widget.Toolbar`（标题、高程 2dp、＋按钮用 Toolbar.LayoutParams 右对齐）
- 会话行 / 通讯录行背景换成系统水波纹，行容器保持白底
- 聊天输入框、搜索框去掉自绘圆角，改用主题默认的 Material 下划线输入框
- 对话框里的输入框也用主题文字色
