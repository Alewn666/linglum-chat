# 灵珑聊天 · 微信化第 1 期（V0.0.8，2026-11-01）

## 做了什么

用户要求「全面改建成微信那样」。微信功能体量大，按三期走（见 `微信化改造_路线图.md`），
本轮落地**骨架 + 通讯录 + 我 + 头像 + 新图标**，服务端也补了对应能力。

### 服务端（`chat/server/app.py`）

| 新增 | 说明 |
|---|---|
| `users.avatar_ver` | 换头像 +1，客户端据此判断要不要重下 |
| `POST /api/profile` | 改昵称 / 换头像（PNG、JPEG，≤400KB，按魔数判断类型） |
| `GET /api/avatar/<wxid>` | 取头像（需登录；没有则 404） |
| `friends(owner,friend,created)` 表 | **通讯录存服务端**，换手机 / 找回账号自动恢复 |
| `POST /api/friends` | 加好友（**双向**、幂等） |
| `GET /api/friends` | 通讯录：昵称 + 公钥 + 公钥版本 + 头像版本 |
| `DELETE /api/friends/<wxid>` | 删好友（双向删） |

迁移：`init_db()` 里加 `avatar_ver` 列与 `friends` 表；老库无损（实测 2 账号 / 120 消息保留）。
存量数据：两个老账号（`<REDACTED_PASSWORD>`、`ceshi`）已按"互相是好友"补了 2 行，升级后通讯录直接有内容。

### 客户端（V0.0.8）

- **底部四页签**：微信 / 通讯录 / 发现 / 我（选中绿色 `#07C160`）
- **微信页**：原会话列表（保留未读红点、时间、最后一条）
- **通讯录页**：新的朋友（加好友）、群聊、我的好友列表（头像 + 昵称），点人 → 发消息 / 看资料（含安全码）
- **发现页**：朋友圈 / 扫一扫 / 红包 —— 占位，明确标注"下一版"
- **我**：名片（头像 + 昵称 + 专属号）、换头像、改昵称、设置、帮朋友找回、同步日志、退出
- **头像**：选图 → 居中裁方 → 压 256px JPEG85 → base64 上传；`avatar_ver` 变化才重下；
  本地缓存 `filesDir/avatars/<wxid>.png`，显示时裁 8dp 圆角；没头像仍用首字母色块
- **加好友**：本地添加的同时写服务端（`POST /api/friends`）
- **登录/冷启动**：`refreshFriendProfiles()` 拉服务端通讯录，补好友、更新昵称/头像版本/公钥
- **新图标**：微信绿渐变圆角底 + 双白气泡（72/96/144 三个密度，PIL 生成）
