# 灵珑聊天 · 扫一扫相机修复（V0.0.16，2026-11-01）

## 用户反馈

截图显示两个问题：
1. **相机预览横躺 90°**（画面里的桌子和显示器都是躺着的）
2. **底部「把对方的二维码放进框里」和「从相册选二维码 / 取消」按钮叠在一起**

## 原因

1. Android 相机传感器天然是**横向**的，竖屏 Activity 里如果不调 `Camera.setDisplayOrientation()`，
   预览就是躺着的。V0.0.14 漏了这一步。
2. 提示 TextView 和按钮条都用了 `Gravity.BOTTOM` 叠在同一个 FrameLayout 底部，必然重叠。

## 修复

- `openCamera()` 里按 **摄像头朝向（前/后）+ 屏幕旋转** 算角度并 `cam.setDisplayOrientation(result)`
  （后摄 `(orientation - screenDeg + 360) % 360`，前摄还要做一次镜像修正）
- 解码：**buffer 不会跟着预览转**，所以按同一角度用 `LuminanceSource.rotateCounterClockwise()` 旋转后再送 zxing，
  另外再兜底试一次 90°，保证任何机型都能出结果
- 底部改成竖排容器（提示在上、按钮在下），加半透明黑底，和预览区分开

告诉我机型，我加一个"手动切换方向"的小按钮兜底。
