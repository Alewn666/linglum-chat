# 灵珑聊天 · 删好友（V0.0.9，2026-11-01）

## 需求

用户："先把删好友的功能加上。"

## 做法

服务端 `DELETE /api/friends/<wxid>` 在上一版（V0.0.8）就存在（双向删、幂等），
本轮把**客户端入口和状态同步**补齐：

| 位置 | 行为 |
|---|---|
| 通讯录 → 点好友 | 菜单从 2 项变 3 项：发消息 / 查看资料 / **删除好友** |
| 删除确认 | 二次确认，二选一：**只删好友（保留聊天记录）** / **删好友并清空聊天记录** |
| 删除动作 | 先 `DELETE /api/friends/<wxid>`（双向）→ 本地移除 → 清 `friends_srv` 清单 → 需要时清聊天记录 |
| 失败处理 | 服务器删不掉（断网）→ **本地照样删**，并明确提示"已在本地删除，但服务器没删掉：原因" |
| 对方侧 | 通讯录以服务端为准：`refreshFriendProfiles()` 现在会**清扫**"上次同步过、这次没了"的好友（比对 `friends_srv`），所以我删了对方后，对方下次刷新通讯录也会消失 |
| 聊天记录 | 选"保留"的话，会话列表里会变成「未添加 · 专属号」，点一下还能重新加回来（微信同款降级） |
| 清记录实现 | `rewriteMessages()` 把内存里的消息整份重写 `messages.jsonl`（先写 `.tmp` 再 rename，不破坏原文件） |

新增代码：`Api.delete()`、`dialogDeleteFriend()`、`deleteFriend()`、`rewriteMessages()`、`msgToJson()`；
`refreshFriendProfiles()` 增加 `friends_srv` 差集清扫。

## 验证

- 服务端：`test_profile_friends.py` 里已有「删好友 → 双方通讯录清空」断言（22 项全过）
- 构建：`versionCode 9 / V0.0.9`，APK 90782 B，md5 `5c962745f76b0bc52eb7699c8de3d22a`（`aapt dump` 确认 code=9）
- 线上：`/api/version` 返回 9 + 同 md5；`/apk/linglum-chat-V0.0.9.apk` 下载 `200 90782`，落盘 md5 与源一致
- 服务端本轮**没改**（DELETE 接口 V0.0.8 已有），未重建镜像

## 已知限制

- 删好友**不会**通知对方弹窗（微信也没有），对方下次刷新通讯录才消失
- 群聊里仍在同一个群（微信也是这样：删好友不退群）
- 清空聊天记录是**不可恢复**的（本地 E2EE 历史，服务端只有密文且没有我的私钥）
