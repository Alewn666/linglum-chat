# 灵珑聊天 · 扫一扫加好友（V0.0.14，2026-11-01）

## 做了什么

用户："先把扫一扫做了，就是扫一扫加好友。"

| 位置 | 功能 |
|---|---|
| 我 → **我的二维码** | 弹出本人的加好友二维码（内容 `linglum://add?wxid=<专属号>`）+ 专属号提示 |
| 发现 → **扫一扫** | 打开相机实时识别二维码；识别到 → 解析专属号 → 查到公钥 → 走原来的「添加好友」确认（显示安全码） |
| 兜底 | 相机权限被拒 / 相机打不开 / 现场光不好 → 面板上有「**从相册选二维码**」，用 zxing 解码图片 |

实现细节：
- 引入 **zxing core 3.5.3**（`libs/zxing-core-3.5.3.jar`，607KB，Maven Central 下载，纯 Java 无 Android 依赖）
- 构建脚本 `build_apk.sh` 两处改动：`javac -classpath libs/*.jar`、`d8 ... libs/*.jar`
- 新增 `QrUtil`（生成二维码 / 解析 `wxid=`）、`QrScan`（相机预览 `Camera.PreviewCallback` → NV21 Y 平面 → `PlanarYUVLuminanceSource` → `MultiFormatReader`，每 4 帧解一次避免吃满 CPU；后台线程解码）
- `AndroidManifest`：加 `CAMERA` 权限（`uses-feature` 标为非必需）+ `QrScan` activity
- 扫码结果为空 / 不是加好友码 / 扫到自己的码 / 已是好友 —— 都有明确提示

## 验证

  ```
  encoded : linglum://add?wxid=<REDACTED_PASSWORD>
  decoded : linglum://add?wxid=<REDACTED_PASSWORD>
  parsed  : <REDACTED_PASSWORD>   → ROUNDTRIP OK
  ```
- 构建：`versionCode 14 / V0.0.14`，APK **344,734 B**（比上版大 250KB = zxing），md5 `9989870da0d5601b757f34900f205621`
- `aapt2 dump badging`：versionCode=14，权限含 CAMERA
- 服务端发布：`/api/version` 返回 14；`/apk/linglum-chat-V0.0.14.apk` 下载 `200 344734`，md5 与声明一致
- 服务端代码**未改**（扫码只产生字符串，查人/加好友复用现有 `/api/pubkeys`、`/api/friends`），未重建镜像

## 已知限制

- 相机用的是老的 `android.hardware.Camera`（兼容面广、代码短），在极端新机型上可能有预览比例问题；
  识别失败时可用「从相册选」
- 二维码内容没有签名/防伪，别人可以伪造一张「加我」的码 —— 加好友确认页仍会显示**安全码**，可当面核对
- 还没有「扫一扫付款/扫小程序」这类能力（路线图里明确不做）
