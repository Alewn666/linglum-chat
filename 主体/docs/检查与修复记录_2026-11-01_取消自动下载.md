# 灵珑聊天 · 取消自动下载更新（V0.0.12）

## 用户要求

> 把当时加上的自动下载给去掉吧，更新还是现下。

## 改动

- 删除 V0.0.10 加的 `silentDownload()` / `promptInstall()` 两个方法（以及启动时"上次已下好"的提示逻辑）
- `checkUpdate()` 恢复成：发现新版本 → **只弹窗提示**（版本号 + 更新说明）→ 用户点「立即更新」才下载（带进度条）→ 下载完调起安装
- 强制更新（服务端 `minVersionCode`）逻辑不变

现在外网/流量环境下不会再有"莫名其妙后台把包下下来"的行为。
