# 灵珑聊天 · 平板三栏适配（V0.0.15，2026-11-01）

## 用户反馈

> 平板端你没做适配。

属实：V0.0.8 做底部四页签时只改了手机，平板还停在老的「左列表 + 右聊天」两栏，
而且走的还是 `showHomeTablet()` 那条旧路径（不看 `currentTab`）。

## 改动

`showHomeTablet()` 重写成**三栏**（对应微信 Pad 版）：

```
┌────┬──────────────┬────────────────────┐
│ 💬 │              │                    │
│ 👥 │  当前页签的   │   聊天区           │
│ 🧭 │  列表（340dp）│  （选中会话时）     │
│ 👤 │              │                    │
└────┴──────────────┴────────────────────┘
 78dp
```

- 最左竖排页签：微信 / 通讯录 / 发现 / 我，选中绿色 `#07C160`（与手机底栏一致），点击 `showTab(i)`
- 中间列按 `currentTab` 分别构建：`buildSidebar`（会话）/ `buildContactsInto` / `buildDiscoverInto` / `buildMeInto`
- 右侧：`openChat != null` → `buildChatInto(right, false)`；否则提示文字（会话页提示"选择一个会话"，其余页提示"点左边列表里的人或会话"）
- 切页签**不清空**右侧正在聊的会话（`showTab` 里原本就有 `if (!tablet) openChat = null;`）
- 手机（smallestWidthDp < 600）布局不变，仍是底部四页签

## 验证

- 构建：`versionCode 15 / V0.0.15`，APK 344,734 B，md5 `f4966a481dd31732565e9de19ae45a27`
- `aapt2 dump badging`：versionCode=15
- 服务端发布：`/api/version` 返回 15；`/apk/linglum-chat-V0.0.15.apk` 下载 `200 344734`，md5 一致
- 代码走查：三栏容器都是 `LinearLayout(HORIZONTAL)`，中列固定 340dp、右列 `weight=1`；
  `buildContactsInto/buildDiscoverInto/buildMeInto/buildSidebar` 四个构建器都只往传入容器里加 View，
  没有依赖"必须从 rootCol 开始"的前提
